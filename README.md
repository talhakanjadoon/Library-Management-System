>> Library Management System

A simple "Library Management System" built in "C++" as a first semester project for the course "Programming Fundamentals".

>> Concepts Used
- Strings
- Arrays
- Structs
- Loops
- Functions
- Conditional Statements (if/else, switch)

>> Features
- Admin login (username: admin, password: 123)
- Student registration and login
- Admin can add books and view borrowed books
- Students can borrow books and view their profile

>> How to Run
1. Open the `.cpp` file in any C++ compiler (e.g., Code::Blocks, Dev-C++, or VS Code)
2. Compile and run the program
3. Follow the on-screen menu

>> Note
No Object-Oriented Programming (OOP) concepts are used in this project.
